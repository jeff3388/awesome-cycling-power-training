# Contributing

Thank you for contributing! Please follow these guidelines.

## Requirements for New Entries

- **Evidence standard:** All protocols and recommendations must cite peer-reviewed sources (RCT, systematic review, or meta-analysis preferred).
- **Accessible links:** Resources must be freely accessible or widely available. Paywalled resources may be listed only if genuinely foundational with no free equivalent — note access status.
- **Active links:** Verify links work before submitting. Broken links are the primary maintenance burden.
- **No commercial bias:** Manufacturer-funded research may be included but must be labelled. Product recommendations require independent supporting evidence.

## Format

Follow the existing format: `- [Title](URL) — One-sentence description including what makes it valuable.`

For research papers: include PubMed ID where possible.

## What Not to Submit

- Anecdotal protocols without evidence base
- Unverified commercial claims
- Duplicate entries
- Links to pages that redirect to paywalls without disclosure

## Process

1. Fork the repository
2. Add your entry in the appropriate section
3. Submit a pull request with a brief description of why the resource is valuable

All submissions are reviewed for evidence quality and relevance.
